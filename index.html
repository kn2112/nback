How to play

Each trial, one square lights up and a letter is spoken.

  • Tap Position if the square is the same one as n trials ago.
  • Tap Letter if the letter is the same as n trials ago.
  • Tap both, one, or neither — any time before the next trial starts.
  • On a keyboard: A = position, L = letter.

A round is 20 + n trials. Scoring counts hits, misses and false alarms, so ignoring the buttons doesn't score well.
